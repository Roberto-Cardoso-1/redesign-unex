# Redesign Landing Page — Unex

Projeto acadêmico desenvolvido para a disciplina de Front-end e UX/UI, focado na reformulação visual e estrutural da landing page institucional da Unex.

## 🚀 Tecnologias
- React
- Vite
- Tailwind CSS

## 💻 Como rodar o projeto localmente
```bash
# Clone o repositório
git clone [https://github.com/Roberto-Cardoso-1/redesign-unex.git](https://github.com/Roberto-Cardoso-1/redesign-unex.git)

# Instale as dependências
npm install

# Inicie o servidor local
npm run dev
